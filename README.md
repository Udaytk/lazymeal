# Lazy Meal Decider

A simple app that suggests quick recipes based on ingredients you have.

## Features
- Type ingredients in one line
- Get 3 quick recipe suggestions
- 5-minute lazy version
- 1-pan cooking option
- Voice-guided cooking mode (Gemini Live API)

## Setup
1. Install dependencies: `npm install`
2. Add your Gemini API key to `.env`
3. Run: `npm start`

## Usage
Type: "I have eggs, bread, ketchup"
Get instant recipe suggestions with voice guidance option.
